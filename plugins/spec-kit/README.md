# GitHub Spec Kit Plugin

Spec-Driven Development (SDD), Bug Fixing, and Idea Assessment toolkit for AI coding agents.

## Features
- **Spec-Driven Development**: Constitution → Specify → Plan → Tasks → Implement → Converge.
- **Bug Fixing Pipeline**: Assess → Fix → Test.
- **Idea Assessment Pipeline**: Intake → Research → Define → Shape → Decide.
- **Direct Chat Slash Commands**: Full support for `/spec`, `/specify`, `/speckit`, and `/speckit-*` commands.

## Getting Started in Chat
- `/spec` - View status and interactive cheatsheet
- `/spec init` - Initialize project with `.specify/`
- `/spec specify <description>` - Create a functional spec
- `/spec plan` - Create an implementation plan
- `/spec tasks` - Generate task checklist
- `/spec implement` - Execute implementation
- `/spec converge` - Verify and converge remaining work
